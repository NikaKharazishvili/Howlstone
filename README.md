# Howlstone

A level-based 3D action-adventure made in Unity 6 (URP), in the spirit of PlayStation 1 licensed platformers: you play a humanoid wolf who throws things, spins through enemies, collects coins and levels up.

**[Play or watch it on itch.io](https://nikson212.itch.io/howlstone)**

## About this repository
This is a **code showcase**. It contains the game's scripts, project settings and documentation. The art, audio, scenes and third-party packs are not included: some are licensed and may not be redistributed, and my own editor tools stay private. To see the game itself, play or watch it on itch.io.

Start here:
- [Documentation](Documentation/AboutTheGame.md): what the game is and how each system works.
- [Scripts](Assets/Scripts): `Core` (helpers, `ClipAnimator`), `Gameplay` (player, enemies, camera), `Managers`, `UI`.

## Controls
| Input | Action |
| --- | --- |
| WASD | Move |
| Q / E | Rotate the camera |
| Space | Jump |
| Shift | Sprint |
| Z | Throw a shuriken |
| X | Spin attack |
| Tab | Toggle the HUD |

Gamepads are supported too.
